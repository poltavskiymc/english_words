# English Words

Приложение для изучения английских слов: карточки с интервальными повторениями, «пары» и тест.
PWA — ставится на телефон и работает оффлайн.

**Живёт тут:** https://poltavskiymc.github.io/english_words/

## Что умеет

- **🃏 Карточки** — слово, тап, перевод и пример. «Дальше» двигает слово по интервалам, «Изян» отправляет в выученные.
- **🔗 Пары** — два столбца по шесть, соединить слово с переводом.
- **✅ Тест** — слово и четыре варианта; ошибка возвращает слово в конец сессии.
- Направление **EN → RU**, **RU → EN** и микс — на каждое слово решается отдельно.
- **Интервальные повторения** (Leitner, уровни 0…6 → 0, 1, 3, 7, 16, 35, 90 дней). Лимит новых слов в день настраивается.
- **🔁 Без расписания** — когда на сегодня всё повторено, кнопка «Начать» переключается на свободную сессию по всем невыученным словам выбранных категорий. Занятие не упирается в «приходи завтра».
- Экран сессии — на всю высоту телефона: тренажёр растягивается, кнопки прижаты к низу, под большой палец.
- «Выучено» переключается кружком прямо в списке слов, без захода в правку.
- Слова: 7 готовых наборов, свои через форму, импорт TSV (файлом или вставкой), генерация набора **ИИ** (DeepSeek по ключу пользователя).
- **Наборы** = категории словаря: и готовые, и свои, и приехавшие импортом. Любой набор убирается целиком, вместе со словами и прогрессом.
- Озвучка отключается в настройках — кнопки 🔊 тогда прячутся совсем.
- Прогресс: серия дней, график за две недели, разбивка по категориям, 19 ачивок.
- Озвучка английского — системным `speechSynthesis`.

## Как устроено

Никакого сборщика и никаких модулей: чистые HTML/CSS/JS, скрипты общаются глобальными функциями,
**порядок подключения в [index.html](index.html) важен**.

```
index.html              разметка всех вкладок
css/styles.css          единственный стиль, светлая/тёмная тема через CSS-переменные
js/data.js              контент: наборы слов, ачивки, промпт для ИИ
js/util.js              esc, склонения, даты, shuffle, озвучка, тосты
js/traffic.js           учёт трафика запросов к DeepSeek
js/nav.js               вкладки и под-вкладки
js/store.js             словарь в localStorage + SRS (единственный, кто пишет ew_words)
js/stats.js             статистика, серии дней, ачивки
js/train.js             три тренажёра
js/decks.js             готовые наборы
js/words.js             список, добавление, импорт/выгрузка TSV, правка
js/ai.js                генерация набора через DeepSeek
js/settings.js          настройки + первичная отрисовка (грузится последним)
sw.js                   оффлайн: HTML — network-first, статика — stale-while-revalidate
```

Данные — только в браузере пользователя (`localStorage`), своего бэкенда нет.
Ключ DeepSeek лежит там же и уходит напрямую в `api.deepseek.com`.

### Формат обмена словами

Один на всё приложение — TSV, по строке на слово:

```
слово	перевод	пример	категория
```

Пример и категория необязательны. Через него идут и импорт файла, и вставка списком,
и ответ ИИ. Если табов в строке нет, парсер принимает и «слово — перевод».

### ⚠️ При изменении любого css/js

Подними версию **в трёх местах**, иначе обновление уедет мимо кеша:

1. `VER` в [sw.js](sw.js)
2. `?v=…` у всех тегов в [index.html](index.html)
3. `APP_VERSION` в [js/settings.js](js/settings.js)
